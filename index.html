01 About

I work on the layer nobody sees until it breaks: clusters, networks, pipelines, and the alerting that tells you which of them is on fire. That has meant standing up a sovereign cloud region in Saudi Arabia from nothing, cutting $100k a month out of an over-provisioned estate, and pulling infrastructure provisioning down from weeks to hours.

Lately I have been pointing LLMs at operations work — an agent that correlates ArgoCD, Grafana, GitLab, PagerDuty, and Jira to root-cause incidents, and a diagnostic system that reasons over vehicle telemetry in a graph database. Outside the day job I judge the CES Innovation Awards and MLH hackathons, speak at infrastructure conferences, and write about what it actually takes to operate platforms under real load.

03 Selected work

HeyClaude — AI SRE agent

A Claude-powered Slack assistant that takes a production alert and works it the way an on-call engineer would: pulling deploy state from ArgoCD, metrics from Grafana, recent changes from GitLab, and incident context from PagerDuty and Jira, then reporting a probable root cause. Root-cause analysis dropped from hours to minutes.

  • Claude
  • Slack
  • ArgoCD
  • Grafana
  • PagerDuty

Fail-closed ArgoCD proxy

Giving an autonomous agent cluster access is a security problem before it is a features problem. This read-only API proxy blocklists paths and scrubs secrets fail-closed, so HeyClaude reads pod logs and application health while Kubernetes Secrets stay unreachable even if the agent asks for them.

  • Go
  • Kubernetes
  • ArgoCD
  • Security

Smart Diagnostics

Vehicle fault diagnosis at Lucid built on an LLM reasoning over a Neo4j graph of vehicle relationships and Elasticsearch telemetry, turning raw signal data into an explanation a technician can act on.

  • LLM
  • Neo4j
  • Elasticsearch

OCI sovereign region buildout

Built Lucid's entire Oracle Cloud footprint in me-jeddah-1 from nothing, to serve KSA Gov customers under data-residency requirements — networking, clusters, CI/CD, and image replication from AWS ECR.

  • OCI

Provisioning: weeks → hours

Replaced hand-rolled cluster builds with Cluster API, ArgoCD app-of-apps, Terraform, and Atlantis, so a new environment became a merge request instead of a project. Cut provisioning time from several weeks to a few hours.
